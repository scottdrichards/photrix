# The portable base: installs on Linux, macOS and Windows and runs everything on
# CPU, or on an Apple Silicon GPU (PyPI's macOS torch has MPS, and the macOS
# onnxruntime wheel has CoreML).
#
# Install with `bun run --filter server python:install`, not by hand. It
# installs this file and then the GPU build for this machine's profile. The
# profiles, their pins and why each pin exists are in ../scripts/python-env.mjs.
#
# torch and torchvision are pinned WITHOUT a local version (+cu126 and so on) on
# purpose. Under PEP 440, `torch==2.9.1` is satisfied by an installed
# `2.9.1+cu126`, so re-running this file never swaps a profile's GPU build back
# to the default one. Bump the version here and in every profile together.
#
# onnxruntime is the CPU package. A GPU profile uninstalls it and installs its
# own (onnxruntime-gpu, onnxruntime-directml), and both use the same `onnxruntime`
# import directory. insightface and faster-whisper depend on `onnxruntime` by
# name, so re-installing this file on its own brings the CPU package back. Run
# python:install again afterwards.
